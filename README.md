# public

Publicly accessible images, icons, and other static assets, organized by project.

## Sumday

| Asset | Purpose |
| --- | --- |
| `sumday/favicon-32.png` | Browser-tab icon (32 × 32) |
| `sumday/apple-touch-icon.png` | Apple touch icon and Apps Script favicon (180 × 180) |
| `sumday/sumday-512.png` | High-resolution icon for home-screen shortcuts (512 × 512) |
| `sumday/sumday.svg` | Editable vector source |

The Sumday sprout uses Lucide artwork. See `sumday/LUCIDE-LICENSE` for attribution and licensing.

Only assets intended for public access belong here. Application code, credentials,
private documents, and user data belong in their respective private repositories.
